# Prognosegenauigkeit von Unternehmensprognosen - DAX 2020-2024

Datensatz zur Projektarbeit I "Empirische Analyse der Prognosegenauigkeit und Determinanten systematischer Verzerrungen in Unternehmensprognosen" (Zeynep Tomruk, DHBW Stuttgart, Oktober 2026)

## Inhalt

Die Excel-Datei enthält folgende Tabellenblätter:
- **Unternehmen**: Stichprobe (28 DAX-Unternehmen), Branchen und KPI-Definitionen
- **Daten**: Vollständiger Datensatz mit 280 Beobachtungen (Prognose, Ist-Wert, Fehlermaße)
- **Auswertung**: MAPE, MAE, Forecast Bias, Trefferquote und t-Test
- **Codebook**: Definitionen und Regeln der Datenerhebung

## Datenquelle

Prognosen und Ist-Werte stammen aus den veröffentlichten Geschäftsberichten der Unternehmen (Berichtsjahre 2019-2024).
